Project notes

Teresa remains a living machine record rather than a new build announcement. 3DBrain's latest machine notes list a Formbot 350 mm frame running Kalico, a CAN-connected H36 toolhead with Dragon ACE and Clockwork 2, and a four-lane Box Turtle MMU using AFC. The Box Turtle enclosure is incomplete, and core calibration work—including input shaping, per-material pressure advance, and extruder calibration—remains open.

The machine's service state needs careful wording. A Raspberry Pi hard shutdown interrupted a print in April 2026, and the cause remains undiagnosed. Klipper and Moonraker were active in a read-only October 12 check, but the notes explicitly say print readiness was not tested. Under-extrusion work and an unresolved discrepancy between the bed-relay configuration and the apparent physical output wiring are also recorded. The Workshop status reflects that troubleshooting state; older operational claims should not be relied on without a fresh check.
