# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: plain static HTML, CSS, and a small JavaScript enhancement layer;
chosen for a simple, dependency-free deployment on Cloudflare Workers Static
Assets (see `wrangler.jsonc`).

## Users

People following Cody Dracars's software and practical maker projects, with a
clear route from a dated Build Log to the current project, related guides, and
useful tools.

## Product Purpose

`dracars.com` is Cody's durable personal home on the web. Dracars Workshop is
the long-term home for real projects: project pages keep the current state,
while Build Logs preserve the dated story of what happened. Guides and useful
tools grow out of that work and remain easy to find.

## Positioning

An honest, personal workshop for making, modifying, repairing, and understanding
useful things—not a portfolio of abstract claims or a storefront.

## Operating Context

Visitors may arrive from a tool, GitHub, a shared link, or a search result.
They should be able to understand the site and reach a tool quickly on a phone
or desktop browser.

## Capabilities and Constraints

- Static site on Cloudflare Workers Static Assets, source hosted in the public `cdracars/dracars.com` repository.
- The homepage currently features TunePrint, STL to STEP for FreeCAD, SafeSync, and
  Local Screen Recorder; `/resources/` lists the full set.
- Ko-fi support destination: `https://ko-fi.com/cdracars66494`.
- No invented testimonials, usage counts, commercial claims, analytics claims, or paid offerings.
- Keep current tools and projects free to use. Add a distinct Shop section only
  when there is a real paid product to present.
- Workshop project pages are the current hub for each project. Build Logs stay
  chronological and are linked to the project they document; updating a project
  page does not rewrite its logs.
- Featured tools use descriptive `dracars.com` subdomains once their Cloudflare Pages DNS records are active.

## Brand Commitments

The voice is direct, calm, and appreciative. Current tools and projects are
free to use; Ko-fi is an optional invitation to support upkeep, never a
prerequisite. Future paid products belong in a distinct Shop section rather
than changing the terms of existing tools.

## Evidence on Hand

- Task Prioritizer: comparison-based task ordering, live at
  `https://task-prioritizer.dracars.com/`.
- Stitch Shaper: stitch-shaping tool, live at
  `https://stitch-shaper.dracars.com/`.
- Local Screen Recorder: private, browser-only recording tool, live at
  `https://screen-recorder.dracars.com/`.
- TunePrint: browser-only OrcaSlicer calibration companion, live at
  `https://tuneprint.dracars.com/`.
- GitHub profile: `https://github.com/cdracars`.

## Product Principles

1. Put the useful thing before the support ask.
2. Say only what the tools demonstrably do.
3. Keep the page small, fast, and legible.
4. Link openly to source and preserve visitor privacy.

## Accessibility & Inclusion

The site should be keyboard-accessible, readable at common mobile sizes, and
meet normal color-contrast expectations.
