This is a working plan, not a promise to ship every idea on a fixed date. Use
evidence from real projects, site activity, and sales to decide what to build
next. Keep Build Logs honest and chronological; turn proven material into
polished Guides.

## Months 1–3 — Build the machine

**Goal:** Make the content system work and prove that people will use it.

- [x] Launch the Build Logs landing page.
- [x] Start documenting real projects with photos, mistakes, changes, and
  outcomes. Keep updating active logs as the work changes.
- [x] Launch the Guides landing page after establishing the Build Logs section.
- [ ] Turn proven build-log material into polished Guides.
- [x] Establish TunePrint; [ ] choose and build its next useful expansion based
  on actual calibration needs.
- [ ] Add 2–3 additional maker tools when real problems justify them.
- [x] Research affiliate infrastructure and record program candidates;
  [ ] apply when useful guides and eligibility are in place.
- [ ] Develop a very small store/product area when there is a real paid product.
- [ ] Launch 2–3 simple Dracars-made products.
- [ ] Earn the first dollar from someone outside Cody's personal circle.

The content flow is:

**Project → Build Log → Guide or Tool → Product opportunity**

For example, the resin workspace starts as a chronological build log. Once the
setup and workflows have been used and tested, the useful parts can become a
setup guide. Build Logs should also help identify which projects deserve Guides.

## Months 4–6 — Find what is pulling traffic

**Goal:** Learn what people find and use, then improve what shows traction.

Track where available:

- Search Console impressions and clicks
- Build Logs people read
- Guides that rank
- Tools that get used
- Affiliate clicks
- Product sales
- Ko-fi support, including referral source when known

**Target:** $100–$500/month. This is a target, not a forecast. Record the actual
period and evidence when assessing progress.

## Months 7–9 — Connect interest to products

Use recurring problems in projects, guides, and tools to test product ideas:

- Printed products and workshop accessories
- Hardware and resin kits
- Digital packs and STL/STEP projects
- Printer modifications

Treat these as opportunities to investigate, not commitments, until people
show interest or buy.

**Target:** $500–$1,000/month.

## Months 10–12 — Double down

Use traffic, tool use, affiliate activity, and sales to decide where to invest:

- If resin content draws interest, build out the resin ecosystem.
- If TunePrint gets repeat use, expand its calibration support.
- If Build Logs attract readers, document more active projects.
- If a product sells, improve it and test related products.

**Target:** Establish a repeatable path to $1,000+/month, with $5,000/month as
the larger long-term goal.
